# Worklog 타임라인

날짜별로 한 일을 기록하고 증빙 캡처를 모아 두는 개인용 웹 앱입니다. 고른 기간의 기록을 「분기별 업무결과물 보고서」 양식에 맞춘 Word와 PDF로 내보냅니다.
디자인은 시안을 그대로 옮겼고, 기능은 React로 다시 만들었습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. 서버가 켜져 있어야 기록을 읽고 쓸 수 있습니다.
데이터 폴더가 비어 있으면 저장소에 들어 있는 `data-sample` 폴더의 예시 기록 17개를 복사해 넣습니다. 날짜는 가장 최근 예시가 오늘이 되게 옮겨서, 언제 열어도 최근 30일 보기에 예시가 보입니다. 주간 기록에서 체크한 뒤 **선택 삭제**로 지우거나, 설정의 "예시 데이터 지우기"로 한 번에 지웁니다.

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 (5173 포트 고정, 기록 저장 기능 포함) |
| `npm run build` | 타입 검사 후 `dist/` 로 빌드 |
| `npm run preview` | 빌드 결과를 4173 포트로 띄움 (기록 저장 기능 포함) |
| `npm test` | 날짜 계산, 보고서 표 내용, Word 문서 구성, 저장 서버, PDF 만들기 테스트 |
| `npm run typecheck` | 화면 코드와 서버 코드 타입 검사 |

## 기록은 어디에 저장되나

기록과 이미지는 **데이터 폴더**(기본: 프로젝트 안 `data`)에 파일로 저장됩니다. 개발 서버가 읽기와 쓰기를 맡고, 밖으로 보내는 것은 없습니다.

```
data/
  settings.json                  부서, 작성자, 도구, 고쳐 쓴 보고 분기
  records/
    2026-10-01_a1b2c3d4/         기록 하나가 폴더 하나 (날짜_기록 id 앞 8자리)
      record.json                제목, 내용, 효과, 도구, 대표 여부
      1.png, 2.png               붙여 넣은 증빙 이미지 원본
  trash/                         지운 기록과 이미지
```

`data-sample` 폴더는 같은 구조의 예시 데이터입니다. 저장소에 함께 올라가고, 처음 열 때와 설정의 "예시 데이터 넣기"에서 여기서 복사해 갑니다. 실제 기록은 `data`에만 쌓이고 `data-sample`은 바뀌지 않습니다.

- **백업**은 데이터 폴더를 통째로 복사하면 됩니다. 설정의 "백업 파일 받기"는 기록과 이미지를 JSON 파일 하나에 담아 줍니다. 다른 PC로 옮기거나 팀원 기록을 모을 때 씁니다.
- **지운 기록**은 바로 없애지 않고 `trash`로 옮깁니다. 되살리려면 `trash`에서 `records`로 폴더를 다시 옮기고 화면을 새로고침하세요. `trash`는 직접 비워야 합니다.
- **저장은 임시 파일에 다 쓴 뒤 바꿔치기**합니다. 저장 중에 꺼져도 반쯤 쓴 파일이 남지 않습니다.
- **폴더 이름**은 탐색기에서 찾기 쉽게 붙인 것입니다. 날짜를 바꾸면 폴더 이름도 바뀌고, 실제 날짜와 제목은 `record.json` 안의 값을 씁니다.
- **`data` 폴더는 `.gitignore`에 들어 있습니다.** 사내 화면 캡처가 들어가니 git 원격 저장소에 올리지 마세요.
- **폴더 위치를 바꾸려면** 프로젝트 폴더에 `.env.local` 파일을 만들고 `WORKLOG_DATA_DIR=D:\경로\worklog-data` 처럼 적은 뒤 서버를 다시 켜세요. 프로젝트 밖 경로면 git 걱정도 없습니다.
- `record.json`이 깨졌거나 이미지 파일이 없으면 화면 위에 알림이 뜹니다. 고친 뒤 "다시 읽기"를 누르면 됩니다.
- 예전 버전(브라우저 IndexedDB에 저장)에서 쓰던 기록은 처음 열 때 데이터 폴더로 자동으로 옮깁니다. 이미 데이터 폴더가 있으면 화면 위의 알림에서 옮길 수 있습니다. 브라우저에 있던 원본은 지우지 않습니다.

### 보안

저장 서버는 이 PC(localhost)에서 연 화면의 요청만 받습니다. 다른 웹사이트가 이 서버로 요청을 보내 기록을 읽거나 바꾸지 못하게 Host, Origin, Sec-Fetch-Site 헤더를 확인하고, 쓰기 요청에는 앱 전용 헤더를 요구합니다. 개발 서버가 `data` 폴더의 파일을 주소로 바로 내주지 않게 막아 두었습니다.

## 쓰는 방법

1. 화면을 캡처(Win+Shift+S)한 뒤 페이지에서 **Ctrl+V** 하면 기록 추가 창이 이미지와 함께 열립니다.
2. 한 줄 제목, 사용한 도구, 효과(이전 방식과 비교)를 적고 저장합니다.
3. 타임라인 점에 마우스를 올리면 증빙 미리보기, 클릭하면 상세 화면이 열립니다. 상세 화면에서도 이미지를 붙여넣거나 끌어놓을 수 있습니다.
4. 주간 기록은 최근 두 주만 펼친 채로 시작합니다.
   오른쪽 위 **모두 펼치기**로 지금 보는 기간의 주를 한꺼번에 펼치고 접습니다.
   검색창에 글자를 넣으면 지금 보는 기간에서 제목, 내용, 효과에 그 글자가 든 기록만 남기고, 그 주들을 모두 펼칩니다.
   띄어쓰기는 가리지 않아서 "화면개선"으로 "화면 개선"도 찾고, 여러 단어를 띄어 쓰면 모두 들어 있는 기록만 찾습니다.
   검색하는 동안에는 "검색 결과 모두 선택"이 검색된 기록만 고르고, 검색에 안 보이는 기록을 골라 둔 채면 선택 수 옆에 "검색 밖 N개 포함"으로 알려 줍니다.
   검색창에서 Esc를 누르면 검색어가 지워집니다.
5. 주간 기록에서 기록을 체크하고(주마다 있는 체크로 그 주 전체, "이 기간 모두 선택"으로 지금 보는 기간 전체를 고를 수 있음) **선택 내보내기**를 누르면 보고서 내보내기 창이 열립니다. 체크한 기록이 문서에 들어가고, 오른쪽에 받을 문서가 그대로 보입니다. **Word 받기**나 **PDF 받기**를 누르면 보이는 그 문서를 받습니다.
   - 왼쪽에서 양식의 모든 칸을 고칠 수 있습니다. 부서, 작성자, 보고 분기와 나머지 다섯 칸(사용 도구와 좌석 등급, 주요 산출물, 활용 사례와 효과, 부서장 의견, 첨부 결과물)은 기록으로 채운 내용에서 시작하고, 고치면 미리보기에 바로 들어갑니다. 팀장이 부서장 의견과 첨부 결과물을 적어 넣는 칸이기도 합니다.
   - 고친 값은 데이터 폴더의 `settings.json`에 저장됩니다. 부서와 작성자는 설정 창의 값과 같고, 보고 분기와 다섯 칸은 그 기간(기록 날짜로 정한 값)을 다시 내보낼 때만 불러옵니다. "되돌리기"를 누르거나 칸을 비우면 기록으로 채운 내용으로 돌아갑니다.
   - 다섯 칸에서 줄 앞부분과 나머지 사이를 칸 두 개로 띄우면 앞부분이 굵게 들어가고, [ ]로 감싼 글은 채울 자리라 흐리게 들어갑니다.
   - 첫 쪽은 전자결재 「분기별 업무결과물 보고서」 양식의 표를 칸 순서대로 채웁니다(부서와 작성자와 보고 분기, 사용 도구와 좌석 등급, 주요 산출물, 활용 사례와 효과, 부서장 의견, 첨부 결과물). 칸 폭, 회색 칸 이름, A4 여백은 결재 양식 문서와 같게 맞췄습니다. 칸마다 옮겨 적고 다듬으면 됩니다.
   - 다음 쪽부터는 기록 표가 날짜순으로 들어갑니다. 기록 하나가 한 줄이고, 왼쪽 칸에 증빙 이미지, 오른쪽 칸에 날짜, 제목, 내용, 효과가 들어갑니다. 이미지가 없는 기록은 두 칸을 합쳐 내용만 넓게 씁니다.
   - 왼쪽 맨 아래 **넣을 기록** 목록에서 체크를 풀면 그 기록이 문서에서 빠집니다. 주간 기록의 체크도 같이 풀리고, 창을 닫기 전에는 목록에 남아 있어서 다시 체크하거나 **모두 넣기**로 되돌릴 수 있습니다.
   - **1쪽 보고서 본문 빼기**를 체크하면 첫 쪽 양식 표 없이 기록 표만 받습니다. 결과물만 따로 내거나 포트폴리오로 쓸 때 고르고, 파일 이름 끝이 `업무기록`으로 바뀝니다(예: 기획팀_2026년3분기_업무기록.pdf). 이때는 문서에 들어가지 않는 작성자와 다섯 칸을 숨기고, 고쳐 둔 내용은 그대로 남습니다. 창을 열 때마다 첫 쪽을 넣는 쪽으로 시작합니다.
   - **이미지를 내용 아래에 크게**를 체크하면 기록 표를 한 칸으로 만들고, 기록마다 날짜, 제목, 내용, 효과를 쓴 뒤 그 아래에 이미지를 표 폭에 맞춰 넣습니다.
     옆 칸에 넣을 때보다 이미지가 두 배 가까이 커서 화면 캡처의 글자가 읽힙니다.
     이미지가 여러 장이면 한 장씩 이어 붙이고, 쪽은 이미지 사이에서 넘어갑니다.
     세로로 긴 캡처는 남은 자리에 들어가지 않으면 다음 쪽으로 넘어가서 앞 쪽 아래가 빌 수 있습니다.
     몇 건을 화면 위주로 자세히 보여 줄 때 고르고, 창을 열 때마다 왼쪽 칸에 넣는 배치로 시작합니다.
   - 보고 분기는 기록이 모두 한 분기 안에 있으면 그 분기로(예: 2026년 3분기(7. 1.~9. 30.)), 여러 분기에 걸치면 기록 날짜 범위로 정합니다. 분기 보고서를 만들려면 분기별 보기에서 그 분기를 고르고 "이 기간 모두 선택" 후 내보내면 됩니다.
   - 도구와 좌석은 설정에서 넣습니다. 부서나 작성자가 비어 있으면 문서에 [부서], [작성자]로 들어갑니다.
   - PDF는 Word가 없는 PC에서 볼 때 씁니다. 미리보기와 같은 문서를 이 PC의 Chrome이나 Edge가 A4로 인쇄해서 만들어서 모양이 미리보기와 같습니다. 둘 다 없으면 인쇄 창이 열리니 대상에서 "PDF로 저장"을 고르세요. 다른 Chromium 계열 브라우저를 쓰려면 `.env.local`에 `WORKLOG_BROWSER=실행 파일 경로`를 적습니다.
   - 결재에 붙이기 전에 미공개 작품명, 실명, 계약 조건 같은 민감 정보가 없는지 확인하세요. 데이터 폴더의 이미지 원본을 바로 첨부해도 됩니다.

## 구조

```
data-sample/             예시 데이터 (data 폴더와 같은 구조, 저장소에 포함)
server/
  plugin.ts              개발 서버와 미리보기 서버에 저장 기능을 붙이는 Vite 플러그인
  api.ts                 /api 주소 처리, 다른 사이트 요청 차단
  storage.ts             데이터 폴더 읽기와 쓰기, trash 이동
  pdf.ts                 Chrome, Edge 로 HTML 을 A4 PDF 로 인쇄
src/
  App.tsx                화면 조립, 대화상자 상태
  hooks/useWorklog.ts    기록 불러오기, 추가, 수정, 삭제, 백업, 예전 기록 옮기기
  lib/
    api.ts               저장 서버와 주고받는 함수
    normalize.ts         record.json, 백업 파일 값 검사 (화면과 서버가 같이 씀)
    legacy.ts            예전 브라우저 저장소 읽기
    dates.ts             날짜 계산 (day number 기준, 시간대 영향 없음)
    report.ts            전자결재 양식 표의 칸 내용
    exportDocx.ts        Word 파일 만들기 (첫 쪽 양식 표, 다음 쪽부터 기록 표)
    exportPdf.ts         Word 미리보기를 인쇄용 HTML 로 바꾸기, 인쇄 창으로 대신 저장
    backup.ts            JSON 백업과 불러오기
  components/            타임라인, 주간 목록, 상세 화면, 폼, 내보내기와 미리보기, 설정 등
  styles/
    worklog.css          시안 원본 스타일 그대로
    additions.css        기능 때문에 더한 스타일
```

## 시안과 달라진 점

- 기록, 이미지, 설정이 데이터 폴더에 파일로 남습니다(시안은 새로고침하면 사라짐).
- 기록 수정과 삭제, 이미지 여러 장 추가와 삭제가 됩니다.
- 사용한 도구(좌석)와 도구 사용 한도 도달 여부를 기록합니다.
- 결재 양식 모양 그대로 채우는 Word와 PDF 내보내기를 더했고, 받기 전에 받을 문서를 그대로 미리 봅니다.
- 오늘 날짜를 실제 날짜로 쓰고, 월과 분기를 해가 바뀌어도 넘길 수 있습니다.
- 보기는 최근 30일, 월별, 분기별, 연도별입니다(시안의 전체 보기 대신 연도별). 기간 제목을 누르면 최근 30일과 월별은 달력, 분기별은 분기, 연도별은 연도를 고르는 창이 열립니다.
- 내보내기는 주간 기록의 선택 내보내기 한 곳으로 모았습니다(시안은 상단과 하단에도 전체 내보내기가 있었고, 보고서 초안도 따로 있었음).
- 타임라인에서 같은 날 기록만 아래로 쌓습니다. 시안은 가까운 날짜끼리도 아래로 내려서 매일 기록하면 점이 계단처럼 매달렸습니다.
- 점이 촘촘해도 마우스에서 가장 가까운 점 하나가 잡힙니다.
